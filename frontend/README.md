# DIAMOND / KBO

날짜별 경기 결과와 박스스코어, 시즌별 선수 기록과 팀 순위, 두 선수의 같은 시즌 기록을 조회하는 반응형 웹 앱입니다. 홈은 일별 출전 기록이 있는 2025년 6월 1일로 열립니다.

## 실행

Node.js 22.12 이상을 사용하는 환경에서 `frontend` 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 출력된 로컬 주소를 엽니다. `npm test`는 데이터 정합성과 화면 상태를 검사합니다. `npm run build`는 정적 배포본을 `dist/`에 생성하고 `npm run preview`는 해당 빌드를 제공합니다.

## 데이터 범위

- `public/data/`에는 팀에서 공유한 2024~2026시즌 CSV가 있습니다. 경기와 영상은 KBO 경기 ID로, 시즌 성적은 선수 ID·시즌·당시 팀으로 연결합니다. 순위에는 해당 시즌 자료의 기준일이 표시됩니다.
- `public/data/daily/`에는 2025년 6월 1일의 타격·투구·이닝·팀별 박스스코어와 경기 비고가 있습니다. 다른 날짜에 종료 경기가 있어도 일별 자료가 없으면 미수집 상태가 표시됩니다.
- 선수 ID가 확정되지 않은 일별 출전 기록은 이름과 경기 성적만 표시합니다. 비어 있는 값은 —로, 기록된 0은 0으로 표시합니다.
- 조회 데이터는 로컬 CSV에서 읽습니다. 선수 사진과 영상은 CSV에 기록된 외부 주소를 사용합니다. 데이터 로딩과 키 매핑 코드는 `records.js`에 있습니다.
